# Häufige Begriffe verstehen

In SchILD-NRW 2 begegnen Ihnen einige Begriffe immer wieder. Diese Übersicht erklärt sie anhand der täglichen Arbeit. Sie müssen dafür weder Datenbanken verwalten noch programmieren können.

## Schülerdaten und Auswahl

| Begriff | Bedeutung im Arbeitsalltag |
| --- | --- |
| Datenbank | Der gemeinsame Datenbestand Ihrer Schule. Darin speichert SchILD beispielsweise Schülerdaten, Klassen, Unterricht und Noten. SchILD-NRW 2 greift direkt auf diese Datenbank zu. |
| Datensatz | Die zusammengehörigen Angaben zu einer Person oder einem anderen Gegenstand, etwa zu einem Kurs. |
| Status | Eine Einordnung wie aktiv, Neuaufnahme oder Abgang. Die Karteikästen bestimmen, welche Status in der Schülerauswahl berücksichtigt werden. |
| Schülerauswahl | Die Personen, die gerade in der Schülerliste angezeigt werden. Im früheren Wiki heißt diese Liste häufig „Container“. |
| Filter | Eine Auswahlregel, mit der Sie die angezeigten Personen eingrenzen, beispielsweise auf eine Klasse oder auf fehlende Angaben. Die Eingrenzung allein löscht keine Schülerdaten. |
| Markierung | Eine Kennzeichnung einzelner Einträge innerhalb der Auswahl. Prüfen Sie beim jeweiligen Arbeitsablauf, ob die gesamte Auswahl oder nur markierte Personen bearbeitet werden. |
| Gruppenprozess | Eine Funktion, die einen Arbeitsschritt für mehrere Personen ausführt. Die passende Schülerauswahl ist deshalb besonders wichtig. |

Eine Einführung finden Sie unter [Schülerliste und Auswahl](/einstieg/grundlagen/container?rubrik=schild2). Danach können Sie mit [Auswählen und filtern](/schild2/auswahl?rubrik=schild2) weiterarbeiten.

## Schule und Unterricht

| Begriff | Bedeutung im Arbeitsalltag |
| --- | --- |
| Katalog | Eine gemeinsame Auswahlliste, zum Beispiel für Fächer, Orte oder Vermerkarten. Ein Katalogeintrag kann bei vielen Personen wiederverwendet werden. |
| Lernabschnitt | Die Angaben zu einem bestimmten Halbjahr oder Quartal. Bei Eingaben und Gruppenprozessen ist entscheidend, welcher Abschnitt ausgewählt ist. |
| Klassenunterricht | Unterricht im Klassenverband. |
| Kursunterricht | Unterricht in einer Lerngruppe, die nicht mit dem üblichen Klassenverband übereinstimmt, beispielsweise im Wahlpflichtbereich oder in der Oberstufe. |
| Stundentafel | Ein vorbereiteter Satz von Unterrichtsfächern, der einer Klasse, einem Jahrgang oder einer Schülergruppe zugewiesen werden kann. |
| Teilleistung | Eine einzelne Bewertungsgrundlage zu einem Fach, beispielsweise eine Klassenarbeit oder eine Mitarbeitsnote. Sie ergänzt die Fachnote. |
| GeR-Niveau | Eine Niveaustufe des Gemeinsamen europäischen Referenzrahmens für Sprachen. Sie beschreibt Sprachkenntnisse. |

Die Einrichtung wird unter [Unterricht und Kataloge](/schild2/unterricht-kataloge?rubrik=schild2) erläutert. Die Verarbeitung für mehrere Personen steht unter [Gruppenprozesse](/schild2/gruppenprozesse?rubrik=schild2).

## Formulare und Dateien

| Begriff | Bedeutung im Arbeitsalltag |
| --- | --- |
| Report oder Reportvorlage | Eine Druckvorlage, die festlegt, welche Daten ausgegeben und wie sie angeordnet werden. Eine Reportvorlage hat häufig die Endung `.rtm`. |
| Report-Explorer | Das Fenster, in dem Sie Reportvorlagen auswählen und verwalten. |
| Reportdesigner | Das Werkzeug zum Bearbeiten einer Reportvorlage, etwa ihrer Textfelder und Anordnung. |
| Reportausgabe | Das aus einer Vorlage und den gewählten Daten erzeugte Dokument. Eine gespeicherte SchILD-Archivdatei mit der Endung `.raf` enthält eine Ausgabe, keine bearbeitbare Reportvorlage. |
| Import | Daten aus einer Datei oder einem anderen Programm übernehmen. |
| Export | Daten für eine Datei oder ein anderes Programm ausgeben. |
| Schnittstelle | Eine vereinbarte Form des Datenaustauschs. Sie legt beispielsweise fest, welche Felder eine Datei enthalten muss. |

Zum Drucken vorhandener Vorlagen beginnen Sie mit [Reports verwalten und drucken](/reporting/verwaltung?rubrik=reporting). Für eigene Vorlagen folgen Sie [Reports erstellen](/reporting/erstellung?rubrik=reporting).

## Technische Begriffe erkennen

| Begriff | Einordnung |
| --- | --- |
| Plugin | Eine Programmerweiterung, die zusätzliche Funktionen bereitstellt. |
| DLL | Eine Programmbibliothek, die andere Programme für bestimmte Funktionen verwenden. |
| UDL-Datei | Eine Datei mit Angaben zur Verbindung mit einer Datenbank. |
| SQL | Eine Sprache zum Abfragen und Ändern von Datenbanken. Für die normale Eingabe in SchILD verwenden Sie die dafür vorgesehenen Fenster. |
| RAP | Die Programmiersprache für zusätzliche Berechnungen und Abläufe im Reportdesigner. Sie ist für das Auswählen und Drucken fertiger Reports nicht erforderlich. |

Die entsprechenden technischen Anleitungen benennen ihre Voraussetzungen. Wenn Sie lediglich Daten eingeben, eine Auswahl treffen oder einen vorhandenen Report drucken möchten, beginnen Sie mit dem dazugehörigen Arbeitsablauf.
