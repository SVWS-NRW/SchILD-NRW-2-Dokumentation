# Tastenkürzel

Mit Tastenkombinationen erreichen Sie häufige Funktionen ohne Maus. Die folgende Übersicht ordnet die Tasten den jeweiligen Aufgaben zu.

| STRG + w         | Word Seriendruck starten                            |
|------------------|-----------------------------------------------------|
| STRG + r         | Alle Filter zurücksetzen                            |
| STRG + i         | Notendateien (enm) importieren                      |
| STRG + p         | Reportexplorer starten                              |
| STRG + a         | Filter I aufrufen                                   |
| STRG + s         | Standard Schulbescheinigung drucken                 |
| STRG + d         | Reportexplorer Standardordner starten               |
| STRG + f         | Schüler suchen                                      |
| STRG + g         | Gruppenprozess auswählen                            |
| STRG + k         | Kurse bearbeiten                                    |
| STRG + n         | Notenmodulexport (enm)                              |
| STRG + m         | Filter auf markierte Schüler einschalten            |
| STRG + b         | Freigabe zur Bearbeitung (bei abgeschalt. Autoedit) |
| STRG + Umsch + k | Direkteingabe im Klassenfilter                      |
