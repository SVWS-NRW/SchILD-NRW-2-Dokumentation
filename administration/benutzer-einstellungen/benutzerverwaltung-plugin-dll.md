# Benutzerverwaltung PlugIn-DLL

Wenn in Schild-NRW bei "Extras/Programm-Einstellungen/Plugins" ein Häkchen vor „Benutzerverwaltung“ gesetzt ist, wird ganz rechts im SchILD-Menü ein neuer Menüpunkt "Benutzer" (mit "Angemeldete Benutzer" und "Benutzerverwaltung") angezeigt. So kann man einfach aus Schild heraus die Benutzerverwaltung aufrufen, ohne den Umweg über UserAdmn.exe zu nehmen.

Beim Aufruf der Benutzerverwaltung wird das Passwort des aktuellen Users nochmals abgefragt.
