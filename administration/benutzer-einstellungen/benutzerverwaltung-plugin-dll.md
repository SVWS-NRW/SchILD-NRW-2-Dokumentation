# Benutzerverwaltung als Plugin einbinden

Das Plugin ergänzt SchILD-NRW 2 um einen direkten Zugang zur Benutzerverwaltung. Nach dem Einschalten müssen Sie das externe Verwaltungsprogramm nicht mehr gesondert starten.

Wenn in SchILD-NRW 2 bei "Extras/Programm-Einstellungen/Plugins" ein Häkchen vor „Benutzerverwaltung“ gesetzt ist, wird ganz rechts im SchILD-NRW 2-Menü ein neuer Menüpunkt "Benutzer" (mit "Angemeldete Benutzer" und "Benutzerverwaltung") angezeigt. So können Sie einfach aus SchILD-NRW 2 heraus die Benutzerverwaltung aufrufen, ohne den Umweg über UserAdmn.exe zu nehmen.

Beim Aufruf der Benutzerverwaltung wird das Passwort des aktuellen Users nochmals abgefragt.
