# Datenbank kopieren

Wenn Sie die Schild-Datenbank kopieren möchten, können Sie wie folgt vorgehen:

Das Hauptverzeichnis ist auf der Festplatte **C:\Schild-NRW** beziehungsweise **C:\Programme(x86)\Schild-NRW**. Öffnen Sie den Arbeitsplatz (Explorer) und navigieren Sie dort hin.

![DB-kopieren-01](/bilder/administration/datenbanken/db-kopieren-01.png)

Bei einer Standardinstallation liegt der Datenbankordner Ihrer Schuldaten in diesem Ordner. Öffnen Sie also den Ordner DB. Falls Sie an Ihrer Schule eine Serverinstallation haben, so müssen Sie das Programmverzeichnis selbst suchen!

Das Datenbankverzeichnis befindet sich auf der Festplatte unter **C:\Programme\Schild-NRW\DB**

![DB-kopieren-02](/bilder/administration/datenbanken/db-kopieren-02.png)

Dies ist Ihre Datenbank: **Schild2000n.mdb**

Darunter befindet sich eine Testdatenbank.

![DB-kopieren-03](/bilder/administration/datenbanken/db-kopieren-03.png)

Klicken Sie mit der rechten Maustaste auf die **Schild2000n.mdb**.

Klicken Sie dann auf *Kopieren*.

![DB-kopieren-04](/bilder/administration/datenbanken/db-kopieren-04.png)

Öffnen Sie nun über den Arbeitsplatz ein Fenster für Ihren USB-Stick.

![DB-kopieren-05](/bilder/administration/datenbanken/db-kopieren-05.png)

Rechte Maustaste.... *Einfügen*!

Fertig!
