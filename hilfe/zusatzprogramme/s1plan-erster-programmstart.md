# S1PLAN:Erster Programmstart

Nach der Erstinstallation erscheint beim Programmstart zunächst ein Hinweis-fenster für die Ersteinrichtung des Programms:

![S1P-001-Ersteinrichtung](/bilder/wiki/s1p-001-ersteinrichtung-adf4370a.jpg)

Nach Klick auf „OK“ ist im Fenster mit der Zugangskontrolle der Benutzerna-men „S1PAdmin“ und das Passwort „schild“ einzugeben. Schließen Sie dieses Fenster mit Klick auf „Anmelden“. Wählen Sie danach das Schuljahr (z.B. 2016, Lernabschnitt 1 für 1. Halbjahr im Schuljahr 2016/17). Im nächsten Fenster wird darauf hingewiesen, dass noch keine Verbindung zur SchILD-Datenbank hergestellt ist.

Dies geschieht im nächsten Fenster

![S1P-002-Zugriffskonfiguration](/bilder/wiki/s1p-002-zugriffskonfiguration-30984c8b.jpg)

Den Schild-Zugriff können Sie über

![S1P-003-Schild-Zugriff](/bilder/wiki/s1p-003-schild-zugriff-ff80866e.jpg)

und Auswahl der zugehörigen Datenbank

![S1P-004-Auswahl_DB](/bilder/wiki/s1p-004-auswahl-db-aaaed1ef.jpg)

steuern.

Wenn im oberen Fenster „SchILDNRW UDL-Datei(\*.UDL) gewählt wurde, kann im unteren Fenster die entsprechende UDL-Datei ausgewählt werden. Beach-ten Sie dabei, dass bei Verwendung der Schild-Standarddatenbank (schild2000n.mdb) der Zugriff über die MDB-Datei erfolgen muss, weil zur Schild-Standarddatenbank keine UDL-Datei existiert.

Über ![S1P-005-Verbindung_testen](/bilder/wiki/s1p-005-verbindung-testen-95c68d69.jpg) erkennt man, ob die Verbindung erfolgreich ist.

Es empfiehlt sich, im folgenden Fenster

![S1P-006-Zugriffsinfo](/bilder/wiki/s1p-006-zugriffsinfo-b89c1209.jpg)

Direkt die Stammdaten abzugleichen. Dies wird nach kurzer Zeit vom Pro-gramm bestätigt.

Verlassen Sie das SchILD-Zugriffs-Fenster durch Klick auf ![S1P-007-speichern](/bilder/wiki/s1p-007-speichern-7acc2b3c.jpg).

Als nächstes können ein oder mehrere Kursprofile festgelegt werden.

Im folgenden Beispiel wurde ein Kursprofil für den Jahrgang 08 und den Kurs-arten AGGT, PUT, WPI und WPII ausgewählt. Die Benutzer BN1 und BN2 (siehe oberes Bild zur SchILD-Zugriffskonfiguration) dürfen dieses Profil verwenden und bearbeiten:

![S1P-008-Kursprofil festlegen](/bilder/wiki/s1p-008-kursprofil-festlegen-f272d263.jpg)

Hier wurde „Wunschspalten“ nicht angeklickt, weil im Bereich WPI Schüler-wünsche nicht zugelassen sein sollten. Das Profil wird zweckmäßig in einem Unterordner „Profile“ von S1Plan ge-speichert. Als sinnvoller Name bietet sich „06-WPI-WPII-AG-PUT“ an. Als Namensendung wird automatisch „.kpp“ vergeben.

Durch Klick auf ![S1P-009-wählen](/bilder/wiki/s1p-009-waehlen-be609f68.jpg) wird das Programm (mit zunächst leeren Fens-tern) gestartet:

![S1P-011-Übersicht](/bilder/wiki/s1p-011-uebersicht-bfd49c35.jpg)

:::info
Falls Beim Klicken auf die obere Menüleiste die ersten Zeilen in den darunter liegenden Fenstern überdeckt werden sollten, wird durch Klick auf das rechts oben stehende Symbol ![S1P-010-Aufklappsymbol](/bilder/wiki/s1p-010-aufklappsymbol-913dcc2b.jpg) die Fensteranordnung korrekt eingestellt.
:::
