# KM2-Programmupdate

<a id="Grundinstallation"></a>

## Grundinstallation

Wenn Sie KM2 noch nicht installiert haben sollten, so laden Sie vom SchILD-NRW Portal das → [Grundinstallationspaket](http://www.svws.nrw.de/index.php?id=betaversionen) herunter.

<a id="Automatisches_Update"></a>

**Hinweis**: Wenn die eigentliche Anwendung (KM2.Exe) ausgetauscht werden muss, so wird das Programm

- automatisch im Hintergrund gestoppt,
- ersetzt und
- wieder gestartet.
