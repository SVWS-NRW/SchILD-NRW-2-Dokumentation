# KM2 aktualisieren

<a id="Grundinstallation"></a>

## Grundinstallation

Wenn Sie KM2 noch nicht installiert haben sollten, so laden Sie vom SchILD-NRW Portal das → [Grundinstallationspaket](https://www.svws.nrw.de/schild-nrw-2/tools-module) herunter.

<a id="Automatisches_Update"></a>

## Automatisches Update

Die einfachste Variante für ein Programm-Update kann mit Hilfe des Programms KM2 selbst durchgeführt werden:


1. Klicken Sie im KM2-Hauptmenü auf Info → Info über KM2 Neu ist die Schaltfläche **Update?** Klicken Sie auf → **Update?**


![KM2_Update_01](/bilder/tools/km2/km2-update-01.png)

*Updateprüfung*


2. Es erscheint ein Dialog, der Sie beim weiteren Update-Prozess begleiten wird. Klicken Sie auf → Start, um die **Updateprüfung** zu starten


![KM2_Update_02](/bilder/tools/km2/km2-update-02.png)

*Updateprüfung starten*


3. In diesem Fall wurde ein Updatepaket gefunden. Die bei Ihnen installierte Version 1.3.2.0 kann durch eine neuere Version 1.3.2.1 ersetzt werden. Klicken Sie auf → **Weiter**.


![KM2_Update_03](/bilder/tools/km2/km2-update-03.png)

*Es gibt eine neue Version!*


4. Es werden Ihnen alle Teile des Update-Pakets angezeigt, die Sie ggf. einzeln für den Download ab- oder anwählen können In diesem Fall handelt es sich nur um eine ausführbare Datei, die nicht abgewählt werden kann. Klicken Sie → **Weiter**. Das eigentliche Update wird nun ausgeführt.


![KM2_Update_04](/bilder/tools/km2/km2-update-04.png)

*Komponenten auswählen und starten*


**Hinweis**: Wenn die eigentliche Anwendung (KM2.Exe) ausgetauscht werden muss, so wird das Programm

- automatisch im Hintergrund gestoppt,
- ersetzt und
- wieder gestartet.
