# S1Plan installieren

Starten Sie das Programm S1Plan-Setup.exe. Bei der Installation erhalten Sie zu Anfang ein Fenster mit wichtigen Informationen für das weitere Vorgehen: S1 - Planungsmodul für SchILD-NRW 2

1\. Nach der Installation und dem ersten Programmstart werden Sie nach Benutzerdaten gefragt. Diese sind:

    - Benutzername: S1PAdmin\
    - Passwort: SchILD-NRW 2\

2\. Legen Sie das Schuljahr und den Abschnitt fest.

3\. Konfigurieren Sie die Verbindung zur SchILD-NRW 2-Datenbank.

4\. Führen Sie einen Abgleich der Stammdaten mit SchILD-NRW 2 aus.

5\. Legen Sie ein Kursprofil an(zum Beispiel "AGGT / alle" : Verwaltung der Arbeitsgemeinschaften für alle Jahrgänge

6\. Wenn in SchILD-NRW 2 bereits Kursdaten eingegeben sein sollten, so rufen Sie den Menüpunkt:

  Abgleich: Kurse / SchILD-NRW 2-Kurse (Alt+A) \
  auf und klicken auf "SchILD-NRW 2-Import"\

Geben Sie nach Klick auf „Weiter“ gegebenenfalls Benutzerinformationen an und klicken Sie wiederum auf „Weiter“. Im folgenden Fenster finden Sie eine voreingestellte Pfadangabe zum Installa-tionsort des Programms. Ändern Sie gegebenenfalls den Pfad nach Ihren Programmein-stellungen zu SchILD-NRW 2 ab. Auf jeden Fall sollte S1Plan in einem Unter-ordner von SchILD-NRW 2 installiert werden. Klicken Sie danach auf „Weiter“ und führen Sie die Installation zu Ende.

## Programm installieren

Die folgenden Arbeitsschritte beziehen sich auf [die Originalquelle, Seiten 6–6](https://www.svws.nrw.de/system/files/media/document/file/s1plan_anleitung.pdf#page=6).

### 3 Erste Schritte

### 3.1 Installation

### SchILD-NRW

Laden Sie das Installationspaket aus dem Internet herunter und spei-

chern die Datei S1Plan-Setup.exe in ein leeres Unterverzeichnis (z.B.

c:\\temp).

Führen Sie die Datei S1Plan-Setup.exe aus (z.B. durch "Doppelkli-

cken").

### SchILDZentral

Verwenden Sie nicht das Installationspaket S1Plan-Setup.exe!

Laden Sie das Zip-Archiv (S1Plan-Setup.zip) mit den neuesten Datei-

en aus dem Internet herunter und entpacken Sie das Paket.

Kopieren Sie die ausführbare Datei S1Plan.exe in das Systemver-

zeichnis von SchILDzentral.

Kopieren Sie alle Dateien aus dem \\Vorlagen- und dem \\Report-Ord-

ner des Zip-Archivs in den \\Vorlagen-Ordner von SchILDzentral.

S1Plan.exe kann nicht direkt aus dem SchILDzentral-Systemordner

aufgerufen werden, sondern nur aus der SchILDzentral-Anwendung

heraus!

Nach der Installation und dem ersten Programmstart werden Sie nach Be-

nutzerdaten gefragt. Diese sind:

Benutzername: S1PAdmin

Passwort: schild

### Erstkonfiguration

1. Geben Sie die sonstigen Einstellungen ein

(Einstellungen werden benutzerspezifisch gespeichert).

2. Geben Sie die sonstigen Einstellungen ein (Einstellungen werden be-

nutzerspezifisch gespeichert)

3. Konfigurieren Sie den SchILD-Zugriff und testen Sie die Verbindung.

4. Legen Sie den Lernabschnitt fest (Schuljahr / Abschnitt).
