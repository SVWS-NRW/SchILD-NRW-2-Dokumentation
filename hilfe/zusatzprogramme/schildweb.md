# SchILDweb

Bei der Verwendung von SchILDweb kann hierüber der Export und der Import der Daten erfolgen.

![Datenaustausch-Schildweb](/bilder/tools/weitere/datenaustausch-schildweb.png)

Bitte beachten Sie, dass es sich bei SchILDweb um ein kostenpflichtiges Modul der Firma Ribeka handelt. Nähere Informationen dazu entnehmen Sie bitte der Anleitung von SchILDweb.
