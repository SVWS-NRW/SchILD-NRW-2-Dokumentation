# Testseite

<a id="Datei"></a>

## Datei

- Drucker einrichten
- Datenbank komprimieren und reparieren
- Benutzer wechseln
- Beenden

<a id="Schulverwaltung"></a>

## Schulverwaltung

- Schule bearbeiten
- Lehrkräfte
- Statistik-Jahrgänge
- Klassen/Versetzungstabelle
- Klassengruppen/Abteilungen

<!-- -->

- Unterrichtsfächer
- Stundentafeln
- Schülerspezifische Kursarten
- Kurse
- Vermerk-Arten
- Zeugnisvorlagen zuordnen
- Teilleistungs-Arten
- Floskeln bearbeiten
- DSGVO-Einwilligungen
- Ankreuzkompetenzen
- Erzieher-Funktionen
- Erzieher mit schulinternen Funktionen
- Personengruppe
- Lernplattformen
- Statistik / amtliche Schuldaten
  - Daten prüfen
    - Gesamtprüfung der Daten
    - Fehlerprotokoll anzeigen
  - Export (mit Modulen von IT.NRW)
    - Schülerdaten (sim.txt)
    - Lehrerdaten (lid.txt)
    - Unterrichtsverteilung (uvd.txt)
    - Abiturdaten (abi.txt)
  - Hilfe bei Problemen
