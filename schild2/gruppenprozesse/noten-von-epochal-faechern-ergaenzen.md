# Noten aus Epochalunterricht ergänzen

Dieser Gruppenprozess ermöglicht das einfache Ergänzen von Epochal-Fächern im aktuellen Abschnitt. Unter Epochal-Fächern versteht man die Fächer, die nur in einem Halbjahr unterrichtet werden. Damit der Gruppenprozess richtig arbeitet, müssen diese Fächer im vorangehenden Abschnitt entsprechend gekennzeichnet sein (Häkchen in der Spalte "Epochen-Unterricht" muss gesetzt sein). Damit diese Häkchen gesetzt werden, markiert man das Fach schon in der [Stundentafel](/schild2/unterricht-kataloge/stundentafeln) als Epochenunterricht.

Wird z.B. Musik in der Jahrgangsstufe 7 nur im ersten Halbjahr unterrichtet und damit auch benotet, so soll diese Note natürlich auch auf dem Versetzungszeugnis erscheinen. Dieser Gruppenprozess ergänzt für die ausgewählte Schülermenge im aktuellen Abschnitt sowohl das Fach als auch die Note.
