# Schulbesuchsjahre neu berechnen

Dieser Gruppenprozess berechnet mithilfe des eingetragenen Einschulungsjahres die Anzahl der Schulbesuchsjahre. Die neu berechneten Schulbesuchsjahre werden auf der Registerkarte [Individualdaten I](/schild2/schueler/individual-daten-i) eingetragen (dieses gilt nur für den Status "Aktiv" und "Extern").

Das Einschulungsjahr befindet sich auf der Karteikarte [Individualdaten II](/schild2/schueler/individual-daten-ii).

Obwohl das Datenfeld für die Schulbesuchsjahre ausgegraut ist, weil hier ein berechneter Wert steht, können Sie dort manuell die Schulbesuchsjahre verändern. Sollte dort also aus irgendeinem Grund ein anderer Wert stehen, als zum Beispiel in der Schulbescheinigung gewünscht, so kann dies einfach "übertippt" werden.

Bitte bedenken Sie aber, dass der Gruppenprozess Schulbesuchsjahre neu berechnen dann wieder den alten Wert einträgt!
