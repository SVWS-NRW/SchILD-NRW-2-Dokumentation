# Status- und Schnellfilter

Mit den Filtern im Bereich **Aktuelle Schülerauswahl** grenzen Sie die Schülerliste ein. Beginnen Sie mit dem Statusfilter und wählen Sie danach bei Bedarf eine Klasse, einen Jahrgang oder eine andere Gruppe. Die Filter verändern die angezeigte Auswahl, nicht die gespeicherten Schülerdaten.

![Aktuelle Schülerauswahl an einem Berufskolleg mit Status-, Klassen-, Jahrgangs-, Fachklassen-, Kurs-, Abteilungs- und Schulgliederungsfilter.](/bilder/einstieg/grundlagen/aktuelle-schuelerauswahl-berufskolleg.png)

## Die passenden Filter wählen

| Filter | Wirkung |
| --- | --- |
| Statusfilter | Berücksichtigt alle angehakten Status, zum Beispiel **Aktiv** oder **Aufnahme**. Sie können mehrere Status gleichzeitig wählen. |
| Klassenfilter | Beschränkt die Schülerliste auf die gewählte Klasse. |
| Jahrgangsfilter | Beschränkt die Schülerliste auf den gewählten Jahrgang. |
| Kursfilter | Zeigt die Schülerinnen und Schüler des gewählten Kurses. |
| Abteilungsfilter | Beschränkt die Auswahl auf die gewählte Abteilung. |
| Schulgliederungsfilter | Beschränkt die Auswahl auf die gewählte Schulgliederung; je nach Schulform eingeblendet. |
| Fachklassenfilter | Beschränkt die Auswahl auf die gewählte Fachklasse; je nach Schulform eingeblendet. |

Die Abbildung zeigt die verfügbaren Filter an einem Berufskolleg. An anderen Schulformen können weniger Auswahlfelder sichtbar sein. Die Filter hängen voneinander ab: Nach der Auswahl eines Jahrgangs werden beispielsweise nur dazu passende Kurse angeboten. Jahrgangsübergreifende Kurse lassen sich bei der Auswahl mit gedrückter **Strg**-Taste einbeziehen.

## Eine Schülergruppe auswählen

1. Haken Sie im Statusfilter die benötigten Status an und bestätigen Sie die Auswahl, falls die Schaltfläche zur Übernahme angezeigt wird.
2. Wählen Sie die passende Klasse, den Jahrgang, Kurs oder einen anderen eingeblendeten Filter.
3. Kontrollieren Sie die Schülerliste und die Zahl der angezeigten Datensätze. Gruppenprozesse und viele Reports arbeiten mit dieser Auswahl.
4. Wenn Sie wieder die Standard-Auswahl benötigen, verwenden Sie [Standard-Auswahl laden](/schild2/auswahl/standard-auswahl-laden).

## Statusfilter und Statusfeld unterscheiden

Im Statusfilter bestimmen Sie nur, welche Schülerstatus angezeigt werden. Den Status einer einzelnen Person ändern Sie im Feld **Status** unter [Individualdaten I](/schild2/schueler/individual-daten-i). Dieses Feld bietet eine Einfachauswahl. Die einzelnen Status und ihre Bedeutung beschreibt [Statusfilter und Schülerstatus](/einstieg/grundlagen/karteikasten).

Für weitere Suchbedingungen verwenden Sie [Filter I](/schild2/auswahl/filter-i) oder die übrigen Funktionen im [Auswahlmenü](/schild2/auswahl/auswahl).
