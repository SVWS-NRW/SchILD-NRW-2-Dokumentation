# Standard-Auswahl laden

Die Auswahl dieses Menüpunktes hebt alle zuvor eingestellten Filterbedingungen auf und es erscheinen alle aktiven Schüler im [Schüler-Container](/einstieg/grundlagen/container). Zuvor markierte Schülerdatensätze bleiben allerdings markiert.

Die gleiche Funktionalität wird mit einem Klick auf die runde Leuchtdiode ausgelöst. ([Iconleiste](/einstieg/grundlagen/iconleiste))

Status grün: kein Filter gesetzt (alle aktiven Schüler werden angezeigt)
