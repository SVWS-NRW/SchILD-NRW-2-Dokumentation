# Fachklassen

Hier werden an den Berufskollegs die vorhandenen Fachklassen eingegeben.

Bitte beachten Sie, dass dieser Katalog aus der Statistik Datenbank (Statkue.mdb) gefüllt wird. Ist die Fachklasse aber einmal übernommen, so wird in Schild-NRW eine eigene Tabelle geführt. Sollte sich eine Bezeichnung also ändern, können Sie diese durchaus "Per Hand" ändern.

Sie können zu jeder Fachklasse die Lernfelder in einem Richtextfeld führen. Dies ist eine Alternative zu der Eingabe bei den [Unterrichtsfächern](/schild2/unterricht-kataloge/unterrichtsfaecher).
