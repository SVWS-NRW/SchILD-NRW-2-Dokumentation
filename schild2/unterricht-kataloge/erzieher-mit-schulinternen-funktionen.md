# Erzieher mit schulinternen Funktionen

![Erzieher-mit-Funktionen](/bilder/schild2/unterricht-kataloge/erzieher-mit-funktionen.jpg)

Im Fenster "Erzieher mit schulinternen Funktionen" werden alle Erzieher aufgelistet, die über die rechte Maustaste auf dem Karteireiter [Erz.-Berechtigte](/schild2/schueler/erz-berechtigte) eine schulinterne Funktion zugewiesen bekommen haben. In diesem Fenster können aber auch Funktionen zu Erziehern hinzugefügt werden.

Mit Klick auf + wird ein neues Fenster („Erzieher mit Funktion hinzufügen“) geöffnet. Mit Hilfe der Alphabet-Knöpfe kann die Person gesucht werden. Bei „Funktion“ wird mit dem Listenknopf etwas für die angeklickte Person ausgewählt.

Was im Feld unter „Zusatz“ eingetragen wird, zeigt sich bei „Zusatz-Info“ (im nächsten Fenster). Unter „Funktionsträger ist“ wird ein Punkt gesetzt vor „1.Person“ oder „2.Person“. Mit „Übernehmen“ wird das Fenster geschlossen. Auch hier ist ein "Excel-Export" möglich.

Mit "Export als Steuerdatei für Serienbrief" wird eine csv-Datei erzeugt, deren Speicherort man wählen (und sich merken) muss. Vor "Nach dem Export Word-Seriendruck starten" kann ein Häkchen gesetzt werden. Es kann ein „Filter auf Funktion“ (nach Auswahl mit Listenknopf) gesetzt werden, so dass nur die Eltern mit der ausgewählten Funktion gezeigt werden.

Mit Schalter "Aufräumen" werden "alle Einträge gelöscht, die mit gelöschten oder nicht-aktiven Schülern verknüpft sind". Da sollte aber Vorsicht geboten sein (Datensicherung!).
