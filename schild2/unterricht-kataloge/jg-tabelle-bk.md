# JG-Tabelle-BK

![JG Tabelle BK](/bilder/wiki/jg-tabelle-bk-668c91e3.jpg)

Typische Jahrgangstabelle für ein Berufskolleg.

An dieser Schulform werden hier für jeden Bildungsgang, je nach Dauer, eigene Statistikjahrgänge angelegt. Die interne Bezeichnung kann natürlich individuell gewählt werden.
