# Benutzung des externen Notenmoduls

[Lesbaren Artikel öffnen](/zeugnisse/vorbereitung/benutzung-des-externen-notenmoduls) · [Originaldaten herunterladen](/dateien/quellen/seite-907.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Das externe Notenmodul ist ein kleines Programm, das es Lehrern ermöglichen soll, alle Noten und Bemerkungen auch auf dem heimischen Computer eingeben zu können und dann in der Schule einlesen zu lassen. Das externe Notenmodul ist auf allen Windows-Rechnern lauffähig, andere Betriebssysteme werden nicht unterstützt.

Für die Bearbeitung im Notenmodul sind in der Regel drei Dateien notwendig:

# das externe Notenmodul selbst
# die Lehrerdatei (mit der Endung *.enz oder *.enm)
# die Datei floskel.txt für vorgefertigte Bemerkungen


[[Datei:ExtMod-01.png]]


Speichern Sie alle drei Dateien in einem Ordner, dies erleichtert Ihnen später das Auffinden der Notendatei und der Bemerkungen. Starten Sie das Notenmodul durch einen Doppelklick auf das Programm ExtNotMod.exe. [[Datei:ExtMod-05.png]]

Sie können nun über den Dialog ''Datei -> Öffnen'' die eigene Notendatei öffnen. Diese Notendatei wird in der Regel mit Ihrem Lehrerkürzel, dem Schuljahresbeginn und dem Halbjahr bezeichnet, für das die Noten erfasst werden sollen.


[[Datei:ExtMod-02.png]]


Bei kennwortgeschützten Notendateien werden Sie nun aufgefordert, das vom Schild-Administrator vergebene Kennwort einzugeben.

[[Datei:ExtMod-04.png]]


Haben Sie einen eigenes Schild-Kennwort, so kann auch dieses abgefragt werden.

[[Datei:ExtMod-03.png]]


Bitte beachten Sie, dass diese Funktionen optional ist und von der Einstellung des Exportes aus Schild-NRW heraus abhängt.
 



----

'''Der Hauptbildschirm'''

Hier sehen Sie nun eine Liste aller Noten, die zu vergeben sind. Dabei kann zwischen zwei verschiedenen Modellen gewählt werden:
# Klassenlehrermodell
# Fachlehrermodell
Dies wird vorher festgelegt, als Folge davon sehen Sie entweder nur die Noten Ihrer Klasse in allen Fächern oder aber ausschließlich die Noten, die Sie als Fachlehrer zu vergeben haben.


[[Datei:ExtMod-06.png]]




----

'''Der Karteireiter für Bemerkungen und Fehlstunden'''


[[Datei:ExtMod-07.png]]


Auf dem zweiten Karteireiter können die Klassenlehrer die Zeugnisbemerkungen und die Bemerkungen zum Arbeits- und Sozialverhalten sowie die Eintragungen zum Außerunterrichtlichen Engagement eingeben.

Ein Doppelklick mit der Maus auf die graue Fläche öffnet ein Editorfenster und die Eintragungen können gemacht werden. Bitte übernehmen Sie alle Änderungen mit OK. Die Texte müssen danach in den grauen Flächen zu sehen sein!

Wenn die Datei floskeln.txt im gleichen Verzeichnis wie das Notenmodul liegt, dann können in der Schule bestimmte Bemerkungen vereinbart werden, die an dieser Stelle mit #+Nummer aufgerufen werden können.

Z.B. kann die Eingabe #+1+ENTER dann den Satz: „$Vorname$ hat das Klassenbuch ordentlich geführt.“ aufrufen, wobei der Vorname später beim Zeugnisdruck von Schild-NRW eingesetzt wird.


[[Datei:ExtMod-08.png]]



Hier hat der Lehrer auch die Möglichkeit, die Fehlstunden einzugeben, wenn diese nach dem Modell der gesamten Fehlstunden eingetragen werden. Bitte informieren Sie sich, welches Modell an Ihrer Schule gewählt wurde.

Die Bereichsnoten können für den Fall eines Hauptschulabschlusses nach Klasse 10 eingetragen werden. Dies findet in aller Regel aber erst in der Konferenz statt.

Über das '''Druckersymbol''' haben Sie die Möglichkeit, sich Listen auszudrucken, mit deren Hilfe Sie die eingegebenen Noten kontrollieren können.

[[Datei:ExtMod-10.png]]



Bitte beachten Sie, dass auch die Notendateien eine kleine Datenbank sind.

Aus diesem Grund brauchen Sie auch keine Eingaben explizit zu speichern. Sie können das Notenmodul durch ''Datei -> Beenden'' einfach schließen.
Bitte achten Sie jedoch darauf, dass die letzte Änderung auch in der Datenbank gespeichert ist. Dies kann man in der Regel durch Drücken der Enter-Taste erreichen.



----

'''Rücktransport'''

Für den Import nach SchILD-NRW wird lediglich die Notendatei benötigt. Senden Sie also die Datei ''Kürzel_2014_1.enz'' oder ''Kürzel_2014_1.enm'' an Ihren SchILD-Administrator zurück.
Achten Sie darauf, dass das Notenmodul vor dem Rücktransport geschlossen ist. Dies kann man daran erkennen, dass die *.ldb-Datei, die beim Öffnen entsteht, automatisch von Windows geschlossen und gelöscht wird. [[Datei:ExtMod-09.png]]
```
