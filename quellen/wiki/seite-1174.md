# Einrichtung des ENM-Moduls unter Ubuntu 18.04

Gesicherte Wiki-Seite · Namensraum 0 · Version 4609 · Stand 2020-06-08.

## Originalquelltext

```text
Das Externe Notenmodul kann auch unter Ubuntu ausgeführt werden.

Starten Sie zur Einrichtung ein Terminal.

Geben Sie dort folgende Befehle ein.

<Code> Sudo apt get update

Sudo apt get install wine

Sudo apt get install winwtricks</Code>

Laden Sie sich das ZIP-Paket von der Homepage herunter:
https://www.svws.nrw.de/download/schild-module

Entpacken Sie das Paket in den wine-Ordner:
Hier im Beispiel $HOME/.wine/drive_c/Schild-NRW/ENM/

Starten Sie das Notenmodul mit dem Befehl:

<Code>wine $HOME/.wine/drive_c/SchILD-NRW/ENM/ENM.exe</Code>
```
