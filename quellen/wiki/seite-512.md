# Noten von Epochal-Fächern ergänzen

Gesicherte Wiki-Seite · Namensraum 0 · Version 2110 · Stand 2014-04-14.

[Lesbaren Artikel öffnen](/schild2/gruppenprozesse/noten-von-epochal-faechern-ergaenzen) · [Originaldaten herunterladen](/dateien/quellen/seite-512.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Dieser Gruppenprozess ermöglicht das einfache Ergänzen von Epochal-Fächern im aktuellen Abschnitt. Unter Epochal-Fächern versteht man die Fächer, die nur in einem Halbjahr unterrichtet werden. Damit der Gruppenprozess richtig arbeitet, müssen diese Fächer im vorangehenden Abschnitt entsprechend gekennzeichnet sein (Häkchen in der Spalte "Epochen-Unterricht" muss gesetzt sein). Damit diese Häkchen gesetzt werden, markiert man das Fach schon in der [[Stundentafeln|Stundentafel]] als Epochenunterricht.

Wird z.B. Musik in der Jahrgangsstufe 7 nur im ersten Halbjahr unterrichtet und damit auch benotet, so soll diese Note natürlich auch auf dem Versetzungszeugnis erscheinen. Dieser Gruppenprozess ergänzt für die ausgewählte Schülermenge im aktuellen Abschnitt sowohl das Fach als auch die Note.
```
