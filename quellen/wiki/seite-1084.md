## Originalquelltext

```text
Starten Sie das Programm S1Plan-Setup.exe. Bei der Installation erhalten Sie zu Anfang ein Fenster mit wichtigen Informationen für das weitere Vorgehen:
S1 - Planungsmodul für SchILD

1. Nach der Installation und dem ersten Programmstart werden Sie nach Benutzerdaten gefragt. Diese sind:
   
     - Benutzername: S1PAdmin
     - Passwort: Schild
	 
2. Legen Sie das Schuljahr und den Abschnitt fest.

3. Konfigurieren Sie die Verbindung zur SchILD-Datenbank.

4. Führen Sie einen Abgleich der Stammdaten mit SchILD-NRW aus.

5. Legen Sie ein Kursprofil an(z.B. "AGGT / alle" : Verwaltung der Arbeitsgemeinschaften für alle Jahrgänge
   
6. Wenn in SchILD-NRW bereits Kursdaten eingegeben sein sollten, so rufen Sie den Menüpunkt: 

   Abgleich: Kurse / SchILD-Kurse (Alt+A) 
   auf und klicken auf "SchILD-Import"

Geben Sie nach Klick auf „Weiter“ ggf. Benutzerinformationen an und klicken Sie wiederum auf „Weiter“. 
Im folgenden Fenster finden Sie eine voreingestellte Pfadangabe zum Installa-tionsort des Programms. Ändern Sie ggf. den Pfad nach Ihren Programmein-stellungen zu SchILD-NRW ab. Auf jeden Fall sollte S1Plan in einem Unter-ordner von SchILD-NRW installiert werden. 
Klicken Sie danach auf „Weiter“ und führen Sie die Installation zu Ende.
```
