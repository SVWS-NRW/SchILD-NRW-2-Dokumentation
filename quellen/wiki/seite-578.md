# Schüler-Datensätze löschen

Gesicherte Wiki-Seite · Namensraum 0 · Version 2247 · Stand 2014-05-24.

[Lesbaren Artikel öffnen](/schild2/gruppenprozesse/schueler-datensaetze-loeschen) · [Originaldaten herunterladen](/dateien/quellen/seite-578.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Dieser Gruppenprozess wird erst freigeschaltet, wenn Schüler mit Löschmarkierung über den Filter ausgewählt wurden und im Datencontainer aufgelistet werden.

Es öffnet sich das Fenster "Schüler-Datensätze löschen":

[[Datei:GP-SchuelerDatensaetzeloeschen.jpg|400px]]

Man hat hier die Möglichkeit, das nach dem Löschen automatisch angelegte Löschprotokoll auszuschalten. Wird ein Protokoll mit den gelöschten Schülerdaten angelegt, können ggf. aus dieser Datei die Daten wieder eingelesen werden.

Klickt man auf die Schaltfläche "Löschaktion durchführen", erfolgt eine erneute Sicherheitsabfrage. Erst wenn diese mit 'Ja' bestätigt wird, erfolgt die endgültige Löschung der ausgewählten Schülergruppe.
```
