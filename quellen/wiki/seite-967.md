# Papierkorb zeigen

Gesicherte Wiki-Seite · Namensraum 0 · Version 3715 · Stand 2015-11-20.

[Lesbaren Artikel öffnen](/schild2/auswahl/papierkorb-zeigen) · [Originaldaten herunterladen](/dateien/quellen/seite-967.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Über dieses Menü können im [[Container]] schnell alle Schüler, die einmal gelöscht wurden, angezeigt werden.

Diese Schüler liegen in einer Art "Papierkorb", damit sie bei versehentlicher Löschung wieder geholt werden können.

Haben Sie die Anzeige des Papierkorbs gewählt, so können Sie über die rechte Maustaste auf den Schülernamen den Menüpunkt "Löschmarkierung aufheben" wählen und der Schülerdatensatz wird wieder hergestellt.

[[Image:Löschung.jpg|Center]]

Es bietet sich aber auch die Möglichkeit, diese Schüler über die [[Gruppenprozesse]] zu behandeln!

Dabei können Sie die Löschmarkierung einer ganzen Schülergruppe zurücknehmen. (Individualdaten ändern > Individual Daten I > Löschmarkierung > "Nein")

Oder Sie können über den Gruppenprozess [[Schüler-Datensätze löschen]] eine ganze Gruppe endgültig aus der Datenbank entfernen.
```
