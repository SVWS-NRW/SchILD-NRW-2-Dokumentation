====Beschreibung====


KPlan ist ein Zusatzprogramm, welches im Downloadbereich zusätzlich zu Schild-NRW heruntergeladen werden kann.
Das Programm benötigt einen Datenbankzugriff auf die Schild-NRW-Datenbank oder auf eine Kopie der Datenbank.
Es ermöglicht den Benutzern eine Verwaltung aller Kurse in der Sekundarstufe I.



[[#top|zurück zum Seitenanfang]]

----

====Installation====

'''Installation über die Setup-Datei'''

Laden Sie die Setup.exe über den Downloadbereich herunter. Führen Sie diese Datei durch einen Doppelklick aus. Eine Installationsroutine leitet Sie durch den Installationsvorgang. Bitte wählen Sie einen Datei-Ort, an dem Sie volle Schreib-/Leserechte besitzen!
Es werden alle benötigten Dateien vom Setup entpackt.


[[#top|zurück zum Seitenanfang]]



----

#Nach der Installation und dem ersten Programmstart werden Sie nach Benutzerdaten gefragt. Diese sind:

#:*Passwort: '''Schild''' 
#Legen Sie das Schuljahr und den Lernbschnitt fest.
