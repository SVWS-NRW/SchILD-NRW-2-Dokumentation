## Originalquelltext

```text
Mit diesem Menü gelangen Sie an folgende Funktionen:

;Drucker einrichten

Hier können Sie die Standardeinstellungen für den Drucker beeinflussen.

;Datenbank reparieren und komprimieren

Diese Funktion steht seit der Version 2.0.7.1 unter "Datei" zur Verfügung.
Dabei wird, wenn Sie der einzige angemeldete User an der Datenbank sind, das Komprimierungstool für Access-Datenbanken von Microsoft aufgerufen.
Es hat sich in der Praxis gezeigt, dass Access-Datenbanken sich nach dieser Reparatur gerade in Netzwerkumgebungen deutlich beschleunigen lassen!

Führen Sie diese Funktion regelmäßig vor größeren Datenbank-Arbeiten oder Druckaufträgen (im Netzwerk) durch.

Diese Funktion steht nur bei Access zur Verfügung!

;Benutzer wechseln

Meldet den aktuellen User ab und einen neuen User (evtl. mit anderen Berechtigungen) an.

;Schließen

Beendet das Programm.
```
