# Abitur-Zulassung berechnen

Gesicherte Wiki-Seite · Namensraum 0 · Version 2029 · Stand 2014-04-02.

[Lesbaren Artikel öffnen](/zeugnisse/sekundarstufen/abitur-zulassung-berechnen) · [Originaldaten herunterladen](/dateien/quellen/seite-490.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Dieser Gruppenprozess realisiert die dritte Stufe der Zulassungsberechnungen.

Wurde der Gruppenprozess [[Kurse algorithmisch markieren]] durchgeführt und sind damit die für die Zulassung relevanten Kurse markiert, so realisiert dieser Gruppenprozess die Berechnung der Abiturzulassung. Schon vorhandene Daten werden überschrieben. Anschließend wird auch hier wieder in einer Textdatei angegeben, welche Schüler für die Abiturprüfung zugelassen werden und welche nicht. Diese Datei kann ausgedruckt oder abgespeichert werden.

Die genauen Ergebnisse der Berechnung können dann unter dem Karteireiter "Abitur" unten links unter Block I eingesehen werden.

Für einen einzelnen Schüler kann der Prozess auch unter dem Karteireiter "Abitur" durch Klicken auf die Schaltfläche "Abitur-Zulassung berechnen" initialisiert werden.
```
