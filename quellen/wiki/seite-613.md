# Standard-Formulare drucken

Gesicherte Wiki-Seite · Namensraum 0 · Version 2370 · Stand 2014-06-02.

[Lesbaren Artikel öffnen](/reporting/verwaltung/standard-formulare-drucken) · [Originaldaten herunterladen](/dateien/quellen/seite-613.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
In Schild-NRW ist es möglich, ausgewählte Formulare in dem Ordner "Standard" innerhalb des Report-Explorers abzulegen. Sie können einem Benutzer das Recht geben, nur Formulare aus diesem Ordner drucken zu können.

Es gibt (mindestens) zwei Wege, um die Standard-Formulare aufzurufen.

Sie rufen das Menü ''Druckausgabe'' auf und wählen dann den Menüpunkt ''Report aus Ordner "Standard" drucken'' aus. 

[[Datei:Drucken-Standard2.png]]


Alternativ können Sie auch den Knopf ''Drucken'' betätigen und dort ''Standard-Formulare drucken'' auswählen. 


[[Datei:Drucken-Standard1.png]]



Es öffnet sich der Ordner Standard des Report-Explorers und Sie können das gewünschte Formular auswählen. (vgl. auch [[Reportexplorer aufrufen]])
```
