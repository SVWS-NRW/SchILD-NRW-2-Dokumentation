# Gelöschte Daten zurückholen

Gesicherte Wiki-Seite · Namensraum 0 · Version 3016 · Stand 2015-04-27.

[Lesbaren Artikel öffnen](/schild2/gruppenprozesse/geloeschte-daten-zurueckholen) · [Originaldaten herunterladen](/dateien/quellen/seite-344.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Über den Gruppenprozess [[Individualdaten ändern]] kann bei den Schülerdatensätzen eine Löschmarkierung gesetzt werden.

Diese Schülerdaten befinden sich dann trotzdem noch in der Datenbank. Dies kann man sich wie den Papierkorb in Windows vorstellen.

Sind (durch Filtern über "Filter I" oder "Attributs-Filter erstellen") nur gelöschte Datensätze im [[Container]], so kann der Gruppenprozess [[Schülerdatensätze löschen]] angestoßen werden.

Dieser Prozess dient dazu, die Sätze endgültig aus der Datenbank zu entfernen!
Dabei kann jedoch eine Protokolldatei erstellt werden.
Für den Fall, dass Sie diese Daten aus der Protokolldatei doch noch wiederherstellen wollen, benutzen Sie bitte diesen Menüpunkt.

Nach dem Aufruf werden Sie aufgefordert, die Protokolldatei auf der Festplatte zu bestimmen.

Danach kann der Wiederherstellungsvorgang abgeschlossen werden.

Bitte beachten Sie, dass die wiederhergestellten Daten immer noch die Löschmarkierung besitzen!
```
