# Aufnahmejahr für Neuaufnahmen zurücksetzen

Gesicherte Wiki-Seite · Namensraum 0 · Version 1542 · Stand 2014-03-04.

[Lesbaren Artikel öffnen](/schild2/gruppenprozesse/aufnahmejahr-fuer-neuaufnahmen-zuruecksetzen) · [Originaldaten herunterladen](/dateien/quellen/seite-351.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Wenn man in Schild-NRW über das "+"-Symbol neue Datensätze aufnehmen will, so erscheint ein Dialog, ob man die Schüler für das aktuelle oder das kommende Schuljahr aufnehmen will.

Nach dem erstmaligen Erscheinen merkt sich Schild-NRW diese Angabe bei allen weiteren Neuaufnahmen.

Möchte man diese Einstellung ohne einen Neustart zurücksetzen, so kann man diese Funktion bemühen.

Bei der nächsten Neuaufnahme erscheint dann wieder der Auswahldialog.
```
