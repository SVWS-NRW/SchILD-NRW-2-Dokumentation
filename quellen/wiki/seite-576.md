## Originalquelltext

```text
== Grundinstallation ==
Wenn Sie KM2 noch nicht installiert haben sollten, so laden Sie vom SchILD-NRW Portal das → [http://www.svws.nrw.de/index.php?id=betaversionen Grundinstallationspaket] herunter.

== Automatisches Update ==
Die einfachste Variante für ein Programm-Update kann mit Hilfe des Programms KM2 selbst durchgeführt werden:
{| class="wikitable"
|-
| Klicken Sie im KM2-Hauptmenü auf Info → Info über KM2 <br>
Neu ist die Schaltfläche '''Update?''' <br><br>
Klicken Sie auf → '''Update?''' <br>
| [[Datei:KM2_Update_01.png|thumb|200px|Updateprüfung]]
|-
| Es erscheint ein Dialog, der Sie beim weiteren <br>
Update-Prozess begleiten wird. <br><br>
Klicken Sie auf → Start, um die '''Updateprüfung''' zu starten
| [[Datei:KM2_Update_02.png|thumb|200px|Updateprüfung starten]]
|-
| In diesem Fall wurde ein Updatepaket gefunden. <br>
Die bei Ihnen installierte Version 1.3.2.0 kann  <br>
durch eine neuere Version 1.3.2.1 ersetzt werden. <br><br>
Klicken Sie auf → '''Weiter'''.
| [[Datei:KM2_Update_03.png|thumb|200px|Es gibt eine neue Version!]]
|-
| Es werden Ihnen alle Teile des Update-Pakets <br>
angezeigt, die Sie ggf. einzeln für den Download <br>
ab- oder anwählen können <br>
In diesem Fall handelt es sich nur um eine <br>
ausführbare Datei, die nicht abgewählt werden kann. <br><br>
Klicken Sie → '''Weiter'''. <br>
Das eigentliche Update wird nun ausgeführt.
| [[Datei:KM2_Update_04.png|thumb|200px|Komponenten auswählen und starten]]
|}

'''Hinweis''': 
Wenn die eigentliche Anwendung (KM2.Exe) ausgetauscht werden muss, so wird das Programm 
* automatisch im Hintergrund gestoppt, 
* ersetzt und 
* wieder gestartet.

[[Kategorie:Konferenzmodul KM2]]
```
