# Datenbank reparieren und komprimieren

Gesicherte Wiki-Seite · Namensraum 0 · Version 4064 · Stand 2016-12-01.

[Lesbaren Artikel öffnen](/administration/datenbanken/datenbank-reparieren-und-komprimieren) · [Originaldaten herunterladen](/dateien/quellen/seite-1103.json) · [Zum Quellenarchiv](/quellen/)

## Originalquelltext

```text
Der Menüpunkt "Datei > Datenbank komprimieren und reparieren"

[[Image:2016-12-01 153211.jpg|Center]]

steht nur bei Access-Datenbanken zur Verfügung.
Es wird dann intern das Tool "Schild-Repair.exe" aufgerufen, dass sich auch im Installationsordner befindet wenn die Schild-NRW-Toolsammlung installiert wurde.

Das Reparaturprogramm überprüft dann auf ungültige Verweise und Eintragungen, die u.U. eine Indexverletzung herbeiführen würden.

Außerdem wird eine Komprimierung der Datenbank durchgeführt, was bei Access zur einer erheblichen Verkleinerung der Speichergröße führen kann.

Das kann u.U. auch den gruppenweisen Druckvorgang von Formularen im Netzwerk beschleunigen.
```
