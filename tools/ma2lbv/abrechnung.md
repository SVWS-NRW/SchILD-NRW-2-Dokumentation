# Abrechnung erstellen und ausgeben

Hier bereiten Sie Mehrarbeitsdaten für die Abrechnung und Ausgabe mit MA2 vor. Legen Sie zuerst den Abrechnungszeitraum fest und wählen Sie danach den passenden Weg zur Übernahme oder Eingabe der Daten.

## Zeitraum und Daten wählen

Beim ersten Start legen Sie den Startmonat eines **sechsmonatigen Abrechnungszeitraums** fest. Für die Abrechnungsdaten bestehen drei Wege:

- Eine unterstützte Abrechnungsdatei mit bereits enthaltenen Mehrarbeitsstunden importieren.
- Lehrkraftdaten aus SchILD-NRW 2 übernehmen und die vergütbaren Stunden und Merkmale anschließend ergänzen.
- Die benötigten Daten vollständig manuell erfassen.

Eine vorhandene Datei wählen Sie über den Pfeil neben **Abrechnung → Abrechnungsdatei festlegen**. Anschließend lesen Sie die Datei über **Abrechnung** ein und kontrollieren die angezeigten Werte.

## Änderungsmitteilungen erzeugen

1. Markieren Sie die betreffende Lehrkraft und die gewünschten Monatsspalten.
2. Öffnen Sie **LBV-Export**.
3. Entscheiden Sie, ob die Angaben nur auf Richtigkeit geprüft, als PDF gespeichert oder zusätzlich gedruckt werden sollen.
4. Kontrollieren Sie den Hinweiseintrag zum Ergebnis. Über dessen Kontextmenü lässt sich die erzeugte PDF anzeigen.

Die Ausgaben liegen im Unterordner `pdf` des Programmverzeichnisses. Für mehrere Lehrkräfte markieren Sie die betreffenden Zeilen und verwenden **LBV-Export (alle markierten Zeilen)**. Dabei entsteht für jede Lehrkraft eine separate Datei.

Die am Bildschirm bearbeiteten Abrechnungsdaten werden als verschlüsselte `.MAA`-Dateien im Unterordner `ma` gespeichert. Die allgemeine Exportfunktion kann die dargestellten Daten außerdem in andere Ausgabeformate überführen.

:::danger Abrechnungszeitraum wechseln
**Datei → Abrechnungszeitraum zuordnen** ordnet den angezeigten Lehrkräften einen neuen sechsmonatigen Zeitraum zu. Dabei werden die bisherigen vergütbaren Stunden, Merkmale und Hinweise gelöscht. Sichern beziehungsweise archivieren Sie den abgeschlossenen Vorgang, bevor Sie diese Funktion verwenden.
:::

Die Versionshinweise zu 3.2.3.2 beschreiben die Umbenennung von MA2LBV in MA2 und die Entfernung des ausgelaufenen Förderanlasses „Nachholen und Ankommen nach Corona“. Ältere Abbildungen und Anleitungen können daher andere Bezeichnungen oder Auswahlmöglichkeiten zeigen.

Quelle: [Bedienungsanleitung MA2, Druckstand 18.03.2024](https://www.svws.nrw.de/system/files/media/document/file/ma2lbv_anleitung.pdf), Seiten 12–20; [Versionshinweise](https://www.svws.nrw.de/system/files/media/document/file/ma2pdf_versionsgeschichte.pdf), Version 3.2.3.2.

Vorgehensweisen:

1. Liegen die Daten für vergütbare Mehrarbeit bereits in einer direkt importier-

baren Form vor, z.B. aus GP-Untis oder einem anderen Schulverwaltungs-

programm, das die Schnittstellen unterstützt (siehe Anhang ► Datenim-

port ), so können Sie diese Daten einlesen, kontrollieren, ausdrucken und

archivieren.

2. Können die Daten nicht eingelesen werden, so haben Sie die Möglichkeit

aus SchILD die Lehrkraftdaten zu importieren (Name, Vorname, Geburtsda-

tum, Teilzeit, Vollzeit, Lehramtsanwärter, LBV-Personalnummer, LBV-Ver-

gütungsschlüssel). Geben Sie anschließend manuell die vergütbaren Mehr-

arbeitsstunden und ggf. die zugeordneten Merkmale ein, erzeugen und dru-

cken Sie die Formulare aus und archivieren Sie die Abrechnungsdaten.

3. Falls auch keine Daten aus SchILD zur Verfügung stehen, können Sie auch

alle Daten manuell eingeben, kontrollieren, drucken und archivieren.

Hinweise zur Programmbedienung:

1. Mit Hilfe des Symbols „Einstellungen “ können Sie Eintragungen für

den Formularkopf und die sonstigen nicht personengebundenen Formular-

felder vornehmen: Dienststelle bzw. Schule, Aktenzeichen, Schulnummer

etc. sowie die Konfiguration des Zugriffs auf die SchILD-Datenbank und die

Verwaltung der Benutzerdaten.

2. Die am Bildschirm angezeigten Daten werden im Unterverzeichnis „\\ma“ in

verschlüsselten Dateien mit der Endung „MAA“ gespeichert. Sie können be-

liebig viele von diesen Dateien anlegen ( ) und wieder öffnen ( ).

3. Gruppenprozesse: Anstatt für jede Lehrkraft einzeln die Änderungsmittei-

lung zu erstellen und auszudrucken, können Sie dies auch für mehrere Lehr-

kräfte als Gruppenprozess vornehmen: Markieren Sie entsprechend die

Lehrkräfte und die Monate und klicken auf „LBV-Export (alle markierten Zei-

len )". Für jede Lehrkraft wird dabei im Verzeichnis „\\pdf“ eine separate

Datei erstellt.

4. Mit „Export“ ( ) können Sie die am Bildschirm angezeigten Daten in ver-

schiedene Formate überführen (z.B. als PDF-Datei oder als Excel-Datei)

oder ( ) an einen Drucker senden.

5. Mit „Bearbeiten ► Zeile hinzufügen / löschen“ ( / ) können Sie Zei-

len für Lehrkraftdaten einfügen bzw. aus der Darstellung löschen.

6. Mit „Datei ► Abrechnungszeitraum zuordnen“ ( ) können Sie den ange-

zeigten Lehrkräften einen neuen sechsmonatigen Abrechnungszeitraum zu

ordnen.

Hinweis: Alle vergütbaren Mehrarbeitsstunden, Merkmale und Hinweise

werden bei dieser Aktion gelöscht!
