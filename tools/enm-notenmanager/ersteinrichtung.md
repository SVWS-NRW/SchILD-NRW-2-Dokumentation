# Ersteinrichtung und Anzeige

Der ENM-Notenmanager erweitert die externe Noteneingabe um Teilleistungen, Fördermaßnahmen und weitere Leistungsdaten. Er öffnet die von der SchILD-Administration ausgegebenen Dateien mit der Endung `.enm` beziehungsweise `.enz`.

## Programm und Notendatei öffnen

Installieren Sie das von der Schule bereitgestellte Programmpaket beziehungsweise verwenden Sie die bereitgestellte portable Ausgabe. Starten Sie **ENM.exe** und wählen Sie im Bereich **Notendatei → Notendatei öffnen** Ihre Datei aus.

Beim ersten Start prüft das Programm die benötigten Dateien. Mit der ausführbaren Datei und einer Notendatei ist die Eingabe bereits möglich. Fehlen Reportvorlagen, können jedoch die vordefinierten Ausdrucke und einzelne Layoutmöglichkeiten fehlen. Eine solche Meldung bedeutet daher nicht automatisch, dass die Noteneingabe unmöglich ist.

## Benötigte Spalten anzeigen

Öffnen Sie **Zusätze → Einstellungen**. Hier legen Sie Zusatzspalten und weitere Anzeigeoptionen fest.

- Blenden Sie fachbezogene Fehlstunden aus, wenn diese an Ihrer Schule ausschließlich durch die Klassenleitung als Summe erfasst werden.
- Aktivieren Sie die Informationen zu Lerngruppen, wenn Sie diese als zusätzliche Auswahlhilfe nutzen möchten.
- **Hinweis auf fehlende Noten** veranlasst eine Kontrolle beim Schließen der Datei.
- **Letzte Notendatei öffnen** öffnet beim nächsten Programmstart die zuletzt benutzte Datei.
- Mit **Enter-Taste = Tab-Taste** kann auch die Eingabetaste zum nächsten Eingabefeld führen.

Die Sichtbarkeit einzelner Teilleistungsspalten steuern Sie außerdem über **Zusätze → Spalten wählen**. Es werden nur die Daten bearbeitet, die die Schule in der Notendatei bereitgestellt hat; zusätzliche Spalten ersetzen nicht die fachliche Vorbereitung in SchILD.
