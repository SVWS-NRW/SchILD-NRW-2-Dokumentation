# Noten, Teilleistungen und Bemerkungen

## Eine Lerngruppe auswählen

In der Hauptansicht stehen die Leistungsdaten zunächst nach Klasse, Fach und Name geordnet. Ein Klick auf Spaltenüberschriften ändert die Sortierung. Über einen Doppelklick im Fenster **Lerngruppen** begrenzen Sie die Anzeige auf eine Gruppe; das Aufheben der Filter stellt die Gesamtübersicht wieder her.

Datensätze mit einem **x** in der Spalte **Fx.** sind fixiert und können nur betrachtet werden.

## Fachbezogene Daten eingeben

| Feld | Eingabe und Besonderheit |
| --- | --- |
| **Note** | Fachnote als zulässiges Kürzel. Ein Doppelklick zeigt die Eingabemöglichkeiten. |
| **Pkte./Punkte** | Punkte der Oberstufe; die zugehörige Note wird ergänzt. |
| **FS/uFS** | Fachbezogene Fehlstunden, soweit die Schule diese Eingabe für das Fach freigegeben hat. Summen werden durch die Klassenleitung erfasst. |
| **M.** | Ein `+` kennzeichnet eine Mahnung; die Anzeige wird rot unterlegt. |
| **Zuw.** | Kurszuweisung. Zulässige Werte lassen sich per Doppelklick anzeigen. |
| **Komp.** | Öffnet per Doppelklick die Kompetenzeingabe. Nach der Bearbeitung mit **Speichern** schließen. |
| Teilleistungsspalten | Nur nutzbar, wenn die Teilleistungen in SchILD den Fächern zugeordnet und für die Anzeige aktiviert wurden. |

Blenden Sie nicht benötigte Teilleistungen über **Zusätze → Spalten wählen** aus, um die aktuelle Eingabe übersichtlich zu halten.

## Angaben der Klassenleitung

Öffnen Sie **Leistungsdaten → Klassenleitung**. Dort werden Gesamtfehlstunden, unentschuldigte Fehlstunden und gegebenenfalls Lernbereichsnoten erfasst. Ein Doppelklick auf das jeweilige Feld öffnet den Editor für Arbeits- und Sozialverhalten, außerunterrichtliches Engagement oder Zeugnisbemerkungen.

Vorbereitete Floskeln lassen sich per Doppelklick übernehmen und anschließend bearbeiten. Platzhalter wie `$Vorname$` können im Text stehen bleiben; das Programm ersetzt sie. Bei mehreren aneinandergereihten Floskeln müssen die Übergänge gegebenenfalls sprachlich angepasst werden. Beenden Sie die Bearbeitung mit **Speichern**.

Fördermaßnahmen erreichen Sie über **Leistungsdaten → Fördern**.
