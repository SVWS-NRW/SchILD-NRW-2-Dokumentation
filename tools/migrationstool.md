# Migrationstool

## Migrationstool





An dieser Stelle können Sie sich kleine Hilfsprogramme herunterladen, die bestimmte Aufgaben im Alltag erledigen. 

Mit dem **Migrationstool** können Sie Schild-NRW-Daten in eine andere Datenbank übertragen. Dabei werden sämtliche **IDs neu zugeordnet** und defekte Einträge aufgespürt.
