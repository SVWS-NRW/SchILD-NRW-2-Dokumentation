# ASDPC

ASDPC32 ist das von IT.NRW bereitgestellte Windows-Programm zur Erstellung und Übermittlung der Amtlichen Schuldaten. Es übernimmt alle statistisch relevanten Daten über eine Importschnittstelle aus SchILD-NRW 3 oder SchILD-NRW 2.

Auf der Downloadseite von IT.NRW finden Sie die Installations- und Updatedateien sowie Anleitungen, Kontaktdaten und weitere Informationen.

🌐 <a href="https://schulverwaltungsprogramme.msb.nrw.de/schulen/download.htm" target="_blank"><strong>Downloadseite von ASDPC32</strong></a>

Bei technischen Fragen zum Programm erreichen Sie den Support von IT.NRW unter 0211 9449 6440.

Während der Statistikphase steht Ihnen IT.NRW außerdem telefonisch für inhaltliche Fragen zur Schulstatistik zur Verfügung.
