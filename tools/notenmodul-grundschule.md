# Notenmodul für Grundschulen

## Notenmodul für Grundschulen Eingabe von Zeugnisnoten und Textbausteinen





Mit dem Notenmodul für Grundschulen können Sie DB3-Zeugnisdateien öffnen und Zeugnistextbausteine sowie Ankreuzkompetenzen bearbeiten. Entpacken Sie die ZIP-Datei in einen beliebigen Ordner und starten Sie das Programm per Doppelklick.
