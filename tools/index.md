# Tools und Zusatzprogramme

Die Zusatzprogramme unterstützen Sie bei Planung, Leistungsbewertung und Datenaustausch. Wählen Sie ein Tool, um seine Übersicht und das zugehörige Themenmenü zu öffnen.

## Themen

| Tool oder Zusatzprogramm | Aufgabe |
| --- | --- |
| [Kurs42](/tools/kurs42?rubrik=tools%2Fkurs42) | Kurse und Blockungen in der gymnasialen Oberstufe planen. |
| [LuPO](/tools/lupo?rubrik=tools%2Flupo) | Oberstufenlaufbahnen beraten und Fachwahlen prüfen. |
| [ASDPC](/tools/asdpc?rubrik=tools%2Fasdpc) | Amtliche Schuldaten für die Schulstatistik aufbereiten. |
| [Notenmodul für Grundschulen](/tools/notenmodul-grundschule?rubrik=tools%2Fnotenmodul-grundschule) | Leistungsdaten und Kompetenzen für Grundschulzeugnisse erfassen. |
| [ENM-Notenmanager](/tools/enm-notenmanager?rubrik=tools%2Fenm-notenmanager) | Noten und Leistungsdaten extern erfassen und übertragen. |
| [Externes Notenmodul](/tools/externes-notenmodul?rubrik=tools%2Fexternes-notenmodul) | Leistungsdaten für weiterführende Schulen eingeben. |
| [KM2 – Konferenzmodul](/tools/km2?rubrik=tools%2Fkm2) | Noten und Konferenzentscheidungen bearbeiten. |
| [PM2 – Prognosemodul](/tools/pm2?rubrik=tools%2Fpm2) | Schulabschlüsse und Versetzungen prognostizieren. |
| [S1Plan](/tools/s1plan?rubrik=tools%2Fs1plan) | Unterricht der Sekundarstufe I planen. |
| [MA2LBV](/tools/ma2lbv?rubrik=tools%2Fma2lbv) | Mehrarbeit erfassen und Abrechnungen erstellen. |
| [Migrationstool](/tools/migrationstool?rubrik=tools%2Fmigrationstool) | Daten für die Migration nach SchILD3 vorbereiten. |
| [Anonymisierungstool](/tools/anonymisierungstool?rubrik=tools%2Fanonymisierungstool) | Personenbezogene Daten für Test- und Supportzwecke anonymisieren. |
| [Import aus Textdateien](/tools/import-textdateien?rubrik=tools%2Fimport-textdateien) | Schülerdaten und weitere Daten aus Textdateien übernehmen. |
| [Schuljahr erhöhen](/tools/schuljahr-erhoehen?rubrik=tools%2Fschuljahr-erhoehen) | Das Schuljahr von Schulungsdatenbanken erhöhen. |
| [Weitere Zusatzprogramme](/tools/weitere?rubrik=tools%2Fweitere) | Weitere Programme zur Kursplanung, Kommunikation und Dateneingabe kennenlernen. |
| [KPlan](/tools/kplan?rubrik=tools%2Fkplan) | Kurse und Lerngruppen planen. |
| [SchILDChat](/tools/schildchat?rubrik=tools%2Fschildchat) | Nachrichten im Schulnetz austauschen. |
| [SchILDweb](/tools/schildweb?rubrik=tools%2Fschildweb) | SchILD-Daten für webgestützte Anwendungen nutzen. |
| [Schnelleingabemodul](/tools/schnelleingabemodul?rubrik=tools%2Fschnelleingabemodul) | Daten über ein ergänzendes Eingabemodul erfassen. |
| [Externe Blockungsprogramme](/tools/blockungsprogramme?rubrik=tools%2Fblockungsprogramme) | Externe Programme zur Blockung und Kursplanung einsetzen. |
