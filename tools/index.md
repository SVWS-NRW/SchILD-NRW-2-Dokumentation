# Tools und Zusatzprogramme

Die Zusatzprogramme unterstützen Sie bei Planung, Leistungsbewertung und Datenaustausch. Wählen Sie ein Tool, um seinen Übersichtsartikel zu öffnen. Im Seitenmenü klappen dazu die zugehörigen Anleitungen auf.

## Themen

| Tool oder Zusatzprogramm | Aufgabe |
| --- | --- |
| [Anonymisierungstool](/tools/anonymisierungstool?rubrik=tools) | Personenbezogene Daten für Test- und Supportzwecke anonymisieren. |
| [ASDPC](/tools/asdpc?rubrik=tools) | Amtliche Schuldaten für die Schulstatistik aufbereiten. |
| [ENM-Notenmanager](/tools/enm-notenmanager?rubrik=tools) | Noten und Leistungsdaten extern erfassen und übertragen. |
| [Externe Blockungsprogramme](/tools/blockungsprogramme?rubrik=tools) | Externe Programme zur Blockung und Kursplanung einsetzen. |
| [Externes Notenmodul](/tools/externes-notenmodul?rubrik=tools) | Leistungsdaten für weiterführende Schulen eingeben. |
| [Import aus Textdateien](/tools/import-textdateien?rubrik=tools) | Schülerdaten und weitere Daten aus Textdateien übernehmen. |
| [KM2 – Konferenzmodul](/tools/km2?rubrik=tools) | Noten und Konferenzentscheidungen bearbeiten. |
| [KPlan](/tools/kplan?rubrik=tools) | Kurse und Lerngruppen planen. |
| [Kurs42](/tools/kurs42?rubrik=tools) | Kurse und Blockungen in der gymnasialen Oberstufe planen. |
| [LuPO](/tools/lupo?rubrik=tools) | Oberstufenlaufbahnen beraten und Fachwahlen prüfen. |
| [MA2LBV](/tools/ma2lbv?rubrik=tools) | Mehrarbeit erfassen und Abrechnungen erstellen. |
| [Migrationstool](/tools/migrationstool?rubrik=tools) | Daten für die Migration nach SchILD3 vorbereiten. |
| [Notenmodul für Grundschulen](/tools/notenmodul-grundschule?rubrik=tools) | Leistungsdaten und Kompetenzen für Grundschulzeugnisse erfassen. |
| [PM2 – Prognosemodul](/tools/pm2?rubrik=tools) | Schulabschlüsse und Versetzungen prognostizieren. |
| [S1Plan](/tools/s1plan?rubrik=tools) | Unterricht der Sekundarstufe I planen. |
| [SchILDChat](/tools/schildchat?rubrik=tools) | Nachrichten im Schulnetz austauschen. |
| [SchILDweb](/tools/schildweb?rubrik=tools) | SchILD-Daten für webgestützte Anwendungen nutzen. |
| [Schnelleingabemodul](/tools/schnelleingabemodul?rubrik=tools) | Daten über ein ergänzendes Eingabemodul erfassen. |
| [Schuljahr erhöhen](/tools/schuljahr-erhoehen?rubrik=tools) | Das Schuljahr von Schulungsdatenbanken erhöhen. |
| [Weitere Zusatzprogramme](/tools/weitere?rubrik=tools) | Weitere Programme zur Kursplanung, Kommunikation und Dateneingabe kennenlernen. |
