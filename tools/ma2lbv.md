# MA2LBV

Das früher MA2LBV genannte Programm heißt seit Version 3.2 MA2. Es unterstützt die Erfassung und den Import von Mehrarbeitsdaten sowie die Erstellung von Änderungsmitteilungen an das LBV.

- [Abrechnung und Ausgabe](/tools/ma2lbv/abrechnung?rubrik=tools%2Fma2lbv)
