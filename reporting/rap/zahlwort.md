# Zahlwort

<a id="RAP-Funktion_&quot;Zahlwort&quot;"></a>
<a id="RAP-Funktion_.22Zahlwort.22"></a>

<a id="signatur"></a>

## Beschreibung

Wandelt eine Zahl in ihre ausgeschriebene Textform um.

```pascal
function Zahlwort(aZahl: String): String;
```

## Parameter

| Parameter | Bedeutung |
| --- | --- |
| `aZahl` | Zahl in numerischer Darstellung |

## Rückgabewert

Zahl in Textform

## Beispiel

```pascal
Label1.Caption:=Zahlwort('3,51');
Ergebnis: 'Drei-Komma-Fünf-Eins'
```
