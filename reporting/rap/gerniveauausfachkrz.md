# GeRNiveauAusFachKrz

<a id="RAP-Funktion_&quot;GeRNiveauAusFachKrz&quot;"></a>
<a id="RAP-Funktion_.22GeRNiveauAusFachKrz.22"></a>

<a id="signatur"></a>

## Beschreibung

```pascal
function GeRNiveauAusFachKrz(FachKrz: String): String;
```


bestimmt das eingetragene Sprachniveau zum Fachkürzel aus der Sprachenfolge

## Parameter

| Parameter | Bedeutung |
| --- | --- |
| `FachKrz` | Fachkürzel aus der Fächertabelle |


## Rückgabewert

Klartextname GeRNiveau

## Beispiel

```pascal
GeRNiveauAusFachKrz('E5');
```
