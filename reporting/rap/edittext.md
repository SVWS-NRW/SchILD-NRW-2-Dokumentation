# EditText

<a id="RAP-Funktion_&quot;EditText&quot;"></a>
<a id="RAP-Funktion_.22EditText.22"></a>

## Signatur

```pascal
function EditPlainText
```

## Beschreibung

Ruft einen Texteditor für Text ohne Formatierung auf.

## Rückgabewert

Text ohne Formatierung.

## Beispiel

```pascal
begin
 Text:= EditPlainText;
end;
```
