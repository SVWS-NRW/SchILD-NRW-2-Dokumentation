# EditText

## Beschreibung

Ruft einen Texteditor für Text ohne Formatierung auf.

```pascal
function EditPlainText
```

## Rückgabewert

Text ohne Formatierung.

## Beispiel

```pascal
begin
 Text:= EditPlainText;
end;
```
