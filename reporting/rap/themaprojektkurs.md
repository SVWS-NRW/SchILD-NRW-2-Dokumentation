# ThemaProjektKurs

## Beschreibung

Liefert das bei den Leistungsdaten des Fachs hinterlegte Thema des Projektkurses.

```pascal
function ThemaProjektkurs
```

## Rückgabewert

Thema des Projektkurses aus den LELS der Fächer

## Beispiel

```pascal
Begin 
 Text := ThemaProjektkurs;
End;
```
