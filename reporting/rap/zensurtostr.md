# ZensurToStr

<a id="RAP-Funktion_&quot;ZensurToStr&quot;"></a>
<a id="RAP-Funktion_.22ZensurToStr.22"></a>

## Signatur

```pascal
function ZensurToStr(aZensur: String): String;
```

## Parameter

```text
aZensur  - Numerische Zensur
```

## Rückgabewert

Zensur im Klartext

## Beispiel

```pascal
Label1.Caption:=ZensurToStr('3');
(*ergibt 'befriedigend'*)
```
