# ZensurToStr

## Beschreibung

Wandelt eine numerische Zensur in die zugehörige Klartextdarstellung um.

```pascal
function ZensurToStr(aZensur: String): String;
```

## Parameter

| Parameter | Bedeutung |
| --- | --- |
| `aZensur` | Numerische Zensur |

## Rückgabewert

Zensur im Klartext

## Beispiel

```pascal
Label1.Caption:=ZensurToStr('3');
(*ergibt 'befriedigend'*)
```
