# SelectErzFunktion

<a id="RAP-Funktion_&quot;SelectErzFunktion&quot;"></a>
<a id="RAP-Funktion_.22SelectErzFunktion.22"></a>

## Signatur

```pascal
function SelectErzFunktion: String;
```

## Beschreibung

Diese Funktion bietet alle im Feld „Funktion“ im Katalog „Erzieher-Funktionen“
gefundenen Einträge zur Auswahl an.

## Rückgabewert

Erzieherfunktion

## Beispiel

```text
Siehe „Filtererzieherfunktion“
```
