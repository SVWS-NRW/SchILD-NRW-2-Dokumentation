# SelectErzFunktion

## Beschreibung

Diese Funktion bietet alle im Feld „Funktion“ im Katalog „Erzieher-Funktionen“
gefundenen Einträge zur Auswahl an.

```pascal
function SelectErzFunktion: String;
```

## Rückgabewert

Erzieherfunktion

## Beispiel

```pascal
Siehe „Filtererzieherfunktion“
```
