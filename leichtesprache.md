# Leichte Sprache

## Worum geht es auf dieser Internet-Seite?

SchILD-NRW 2 ist ein Computer-Programm für Schulen.\
Menschen in der Schule arbeiten mit dem Programm.

Mit dem Programm kann eine Schule zum Beispiel:

- Kinder an der Schule anmelden.
- Klassen einteilen.
- Noten eintragen.
- Zeugnisse erstellen.

Auf dieser Internet-Seite gibt es Anleitungen für das Programm.\
Eine Anleitung erklärt eine Aufgabe Schritt für Schritt.

## Wie finde ich eine Anleitung?

Oben auf der Seite gibt es ein Menü.\
In dem Menü stehen verschiedene Themen.\
Wählen Sie ein Thema aus.

Oben gibt es auch eine Suche.\
Wählen Sie **Suchen**.\
Schreiben Sie ein Wort in das Such-Feld.\
Zum Beispiel **Zeugnis**.\
Dann können Sie eine passende Anleitung öffnen.
