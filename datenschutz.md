## Aufruf der Dokumentation

Beim Seitenaufruf erhält der jeweilige Webserver die IP-Adresse Ihres Anschlusses und technische Angaben zur Anfrage. Diese Daten ermöglichen die Auslieferung der Seite. GitHub speichert die IP-Adresse bei Besuchen auf GitHub Pages nach eigenen Angaben zu Sicherheitszwecken. [Hinweise zu GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [Datenschutzerklärung von GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

Die Website stellt statische Artikel und eine Suche bereit, die im Browser läuft. Einige Artikel verlinken auf YouTube-Videos. Beim Öffnen eines solchen Links übermittelt der Browser technische Verbindungsdaten an YouTube. Wenn Sie zu einer externen Website wechseln, gelten die Hinweise des jeweiligen Anbieters. [Datenschutzerklärung von Google](https://policies.google.com/privacy?hl=de)

## Kontaktaufnahme und Ihre Rechte

Bei einer Anfrage verarbeitet die zuständige Stelle die von Ihnen mitgeteilten Angaben, um Ihr Anliegen zu bearbeiten. Bitte senden Sie keine Schülerdaten. Informationen zur Kontaktaufnahme und zu Ihren Rechten, etwa Auskunft, Berichtigung und Löschung, finden Sie in den [Datenschutzhinweisen der Schulverwaltungssoftware NRW](https://www.svws.nrw.de/datenschutz-svws).

Sie können sich bei der [Landesbeauftragten für Datenschutz und Informationsfreiheit Nordrhein-Westfalen](https://www.ldi.nrw.de/) beschweren.
