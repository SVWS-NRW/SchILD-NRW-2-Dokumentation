# Import der Zeugnisformulare in Schild-NRW

Laden Sie sich das benötigte Paket mit Zeugnisformularen von der Homepage **[www.svws.nrw.de](http://www.svws.nrw.de)**.

Unter *Downloads ➜ SchILD-Reports* finden Sie die Zeugnisformulare nach Schulform sortiert.

Sie finden ebenso weitere Reports, die im Rahmen von Versetzungs- und Abschlussberechnungen oder dem Abitur (ZAA) relevant sein könnten. Werden Sie ebenfalls einen Blick auf die überarbeitete *Basisreportsammlung*.

Laden Sie das gewünschte Paket als zip-Datei herunter und entpacken Sie das Archiv in einen Ordner Ihrer Wahl.

:::info
Ein Klick mit der rechten Maustaste in Windows öffnet das Kontextmenü, das die Option zum Entpacken anbietet.
:::

Verschieben Sie nun die entpackten Dateien in das *Schild-Reports-Verzeichnis* Ihrer SchILD-NRW-Installation. Es empfiehlt sich, einen Unterordner für *Zeugnisse* anzulegen, ebenso ist zu empfehlen, die Zeugnisse in einen Ordner des aktuellen Halbjahres zu legen.

:::example
C:\Schild-NRW\Schild-Reports\Zeugnisse\SJ 2024_25_H1\\
:::

Die Zeugnisse benötigen keine eigenen Köpfe und Füße.

Öffnen Sie nun die Druckausgabe in SchILD-NRW. Sollten die Zeugnisformulare nicht sichtbar sein, so betätigen Sie bitte die Schaltfläche zur Aktualisierung.
