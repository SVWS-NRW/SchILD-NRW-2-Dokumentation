# Grundschulzeugnisse Textzeugnis

Seit dem Schuljahr 2020/21 ist es möglich mit Schild-NRW an der Grundschule auch Textzeugnisse mit dem Reportexplorer zu erstellen. Dazu wurde ein RTM-Report für die Reportverwaltung in Schild-NRW entwickelt. Das Paket besteht aus einem Zeugnis-Kopf-RTM einem Hybridzeugnis-RTM und einer INI-Datei.

Ein Zeugniskopf kann im Reportexplorer im Unterordner Subreports gespeichert werden, dann wird dieser Kopf für alle Zeugnisformulare verwendet. Wenn das Kopf-RTM direkt neben dem Hybridzeugnis-RTM im selben Ordner liegt, dann wird er von dem Formular "alleine" verwendet. Die INI-Datei muss immer neben dem Report gespeichert sein.

Die RTM-Zeugnisse ermöglichen mehrere Dinge:

- die Zeugnistexte und Noten könenn mit dem Notenmodul oder SchildWeb geholt werden
- die Zeugnisse können aus Schild-NRW gedruckt werden
- alle Zeugnisse können in die Dokumentenverwaltung gedruckt werden
- Einstellungen für die Zeugnisse können in der INI-Datei gemacht werden

Grundsätzlich liegt im Downloadbereich von svws.nrw.de eine komplette PDF-Anleitung. Aus diesem Grund soll hier auch nicht das gesamte Verfahren erklärt werden. Hier gibt es zusätzlich Hilfe, Tipps und Tricks.
