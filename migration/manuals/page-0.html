Tools & Module

Notenmodul für Grundschulen Eingabe von Zeugnisnoten und Textbausteinen

Mit dem Notenmodul für Grundschulen können Sie DB3-Zeugnisdateien öffnen und Zeugnistextbausteine sowie Ankreuzkompetenzen bearbeiten. Entpacken Sie die ZIP-Datei in einen beliebigen Ordner und starten Sie das Programm per Doppelklick.

⬇️ Notenmodul für Grundschulen ZIP v3.0.2.2

📄 Anleitung Notenmodul für Grundschulen PDF
🌐 Anwenderforum & Community

ENM-Notenmanager für weiterführende Schulen Eingabe von Zeugnisdaten und Teilleistungen

Der ENM-Notenmanager ist ein Windows-Programm zur Bearbeitung von ENM- und passwortgeschützten ENZ-Notendateien auf dem heimischen PC. Entpacken Sie die ZIP-Datei in einen beliebigen Ordner und starten Sie das Programm per Doppelklick. Alternativ bieten wir ein Windows Installationsprogramm.

⬇️ ENM-Notenmanager Setup EXE v1.4.9.2 (gezippt)
⬇️ ENM-Notenmanager Portable ZIP v1.9.4.2

📄 Anleitung ENM-Notenmanager PDF
🌐 Anwenderforum & Community

Externes Notenmodul für weiterführender Schulen (veraltet) Eingabe von Zeugnisdaten

Das alte externe Notenmodul ist ein Windows-Programm zur Bearbeitung von ENM- und passwortgeschützten ENZ-Notendateien. Im Gegensatz zum neuen externen Notenmanager unterstützt es keine Teilleistungen oder Förderpläne. Das Programm wird als ZIP-Paket bereitgestellt und kann nach dem Entpacken ohne Installation gestartet werden. Zusätzlich stehen alternative Reports für den Notenausdruck zur Verfügung.

⬇️Externes Notenmodul Portable ZIP v3.0.2.2 (veraltet)
⬇️Externes Notenmodul Reports (veraltet)

KM2 das Konferenzmodul

Das Konferenzmodul KM2 für SchILD-NRW 2 unterstützt Zeugniskonferenzen durch die Darstellung von Notenübersichten für Klassen und einzelne Schülerinnen und Schüler. Über eine direkte Anbindung an die SchILD-NRW-Datenbank können Notenänderungen und Bemerkungen während der Konferenz übernommen werden. 

⬇️ KM2 Setup EXE v1.9.6.3 (gezippt)
⬇️ KM2 Portable v1.9.6.3 ZIP

📄 Versionsgeschichte KM2 PDF
🌐 Anleitung KM2 im SchILD-NRW 2 - Wiki.
🌐 Anwenderforum & Community

PM2 Das Prognosemodul

PM2 – Prognosemodul für SchILD-NRW 2 unterstützt Gesamt- und Sekundarschulen in NRW bei der Ermittlung von Schulabschlüssen und Abschlussprognosen gemäß APO-SI. Das Programm kann Notendaten aus SchILD-NRW oder aus CSV-Dateien analysieren und die ermittelten Prognosen zurückschreiben.

⬇️ PM2 Setup EXE v1.8.3 (gezippt)
⬇️ PM2 Portable v1.8.3 ZIP

📄 Anleitung PM2 PDF
📄 Versionsgeschichte PM2 PDF
🌐 Anwenderforum & Community

S1Plan Kursplanung für die Sekundarstufe I

S1Plan ist ein Zusatzprogramm für SchILD-NRW 2 zur Verwaltung von Kursen in der Sekundarstufe I. Darüber hinaus bietet es eine Unterrichtsverteilungsübersicht (UV-Übersicht) und unterstützt die Pflege von Stundentafeln in SchILD-NRW 2.

⬇️ S1Plan Setup EXE v1.4.4.1 (gezippt)
⬇️ S1Plan Portable ZIP v1.4.4.1

📄 Anleitung S1Plan PDF
🌐 Bedienungsanleitung im SchILD-NRW 2 - Wiki
🌐 Anwenderforum & Community

MA2LBV Mehrarbeitsabrechnungen für das LBV

MA2LBV ist ein Windows-Programm zur automatisierten Erstellung von Änderungsmitteilungen für das Landesamt für Besoldung und Versorgung NRW (LBV). Mehrarbeitsdaten können über eine allgemeine Schnittstelle – beispielsweise aus GP-Untis – importiert, geprüft und direkt in die erforderlichen Formulare übernommen werden.

⬇️ MA2LBV Setup EXE v3.2.3.2 (gezippt)
⬇️ MA2LBV Portable ZIP v3.2.3.2

📄 Anleitung MA2LBV PDF
📄 Verfahrensverzeichnis MA2LBV DOC
📄 Versionsgeschichte MA2LBV PDF
🌐 Anwenderforum & Community

Migrationstool

An dieser Stelle können Sie sich kleine Hilfsprogramme herunterladen, die bestimmte Aufgaben im Alltag erledigen. 

Mit dem Migrationstool können Sie Schild-NRW-Daten in eine andere Datenbank übertragen. Dabei werden sämtliche IDs neu zugeordnet und defekte Einträge aufgespürt.

⬇️ Migrationstool
🌐 Anleitung Migrationstools im SchILD-NRW 2 - Wiki

Anonymisierungstool

Mit dem Anonymisierungstool können Sie personenbezogene Daten einer bestehenden Schild-NRW Access-Datenbank komplett anonymisieren. Das Programm ist selbsterklärend. 

⬇️ Anonymisierungstool

Schuljahr Erhöhen

Mit dem Programm Schuljahr Erhöhen können Fachberater Schulungsdatenbanken mit einem Klick um ein Schuljahr erhöhen. 

⬇️ Schuljahr Erhöhen

Import aus Textdateien

Das Programm für den Import aus Textdateien hilft Ihnen beim Datenimport in die Schild-Datenbank, welche die Daten nicht dem Format der Standardschnittstelle entsprechen. Das Programm muss in das Installationsverzeichnis von Schild-NRW kopiert werden. Es kann in Schild-NRW über den Menüpunkt Datenaustausch > Import aus Textdatei aufgerufen werden. 

⬇️ Import aus Textdatei
🌐 Anleitung Import aus Textdateien im SchILD-NRW 2 - Wiki
